# 국내 상장 ETF 전체 유니버스 설계

작성일: 2026-10-10

## 목적

- 연금 모멘텀 전략의 후보를 손으로 고른 60개(`config/universe_kr_pension.csv`)가 아니라 **거래 가능한 국내 상장 ETF 전체**로 넓힌다.
- 용도: **매달 순위·선택**. 연구 결과(백테스트·워크포워드)는 비교용으로만 한 번 다시 돌린다. 상장폐지 ETF가 목록에 없어(생존 편향) 과거 성과가 부풀려질 수 있으므로, 기존 60개 연구 수치를 대체하지 않는다.
- 실제로 살 수 없는 종목이 선정되면 사용자가 매수하지 않는다(2026-10-10 결정). 투자 비중·주문 기능은 다루지 않는다.

## 1. ETF 목록과 제외 규칙

- 출처: 네이버 금융 ETF 목록 `https://finance.naver.com/api/sise/etfItemList.nhn` (2026-10-10 기준 1,172개). 항목: 종목코드, 이름, 분류(`etfTabCode`), 거래대금(`amonut`, 백만 원).
- 야후 티커는 `<종목코드>.KS`.
- 제외:
  - 분류 3(국내 파생: 레버리지·인버스), 6(채권·금리·머니마켓), 7(기타: 채권혼합·TDF 등).
  - 이름에 `레버리지`, `인버스`, `2X`(대소문자 무시)가 들어간 ETF. 다른 분류에 섞인 레버리지·인버스(약 70개)를 거른다.
- 포함: 커버드콜, 해외 합성·선물형, 원자재.
- 항상 포함: 현금 ETF `153130.KS`(KODEX 단기채권, 분류 6이라 위 규칙으로는 빠짐)와 벤치마크 `069500.KS`. 목록에 없으면 오류로 멈춘다.
- 야후에서 가격을 받을 수 없는 티커는 경고하고 뺀다. 빠진 티커가 남으면 가격 캐시가 저장되지 않아(부분 다운로드는 캐시하지 않음) 매 실행마다 전체를 다시 받게 되기 때문이다.

## 2. 그룹 (같이 움직이는 ETF 묶기)

- 데이터: 벤치마크(`069500.KS`)의 실제 거래일 기준 최근 252일, 원자료 종가의 일간 수익률.
- 상관계수: 두 ETF가 함께 관측된 날이 63일 이상일 때만 계산한다. 그보다 짧으면 상관을 모르는 것으로 보고 묶지 않는다.
- 묶는 방법: **완전 연결(complete linkage)**. 그룹 안의 **모든 쌍**의 상관이 0.9 이상일 때만 합친다. A–B, B–C가 0.9 이상이어도 A–C가 0.9 미만이면 A와 C는 같은 그룹이 될 수 없다(사슬 연결 방지).
- 합치는 순서: 상관이 가장 높은 그룹 쌍부터. 같은 값이면 티커 순서로 정해 결과가 매번 같다.
- 그룹 이름: 그룹에서 거래대금(네이버 목록 기준)이 가장 큰 ETF 이름. 한 ETF만 있는 그룹은 빈 값(혼자 한 그룹, 기존 규칙과 같음).
- 상장 3개월(63거래일) 미만 ETF는 혼자 한 그룹이다. 다음 달 다시 만들 때 묶일 수 있다.

## 3. 계좌·자산 표시

- `pension_ok=1`: 전부(연금저축은 레버리지·인버스만 불가이고 이미 제외됨).
- `retirement_ok=0`: 이름에 `합성` 또는 `선물`이 들어간 ETF. 퇴직연금의 파생형 ETF 제한을 이름으로 근사한 규칙이다(정확한 판정은 위험평가액 기준이라 증권사 화면과 다를 수 있다).
- `risk_asset=0`: 현금 ETF `153130.KS`만. 나머지는 1.
- `proxy`: 기존 `config/universe_kr_pension.csv`에 있던 상장 전 대체 이력(프록시) 설정을 같은 티커에 옮긴다. 다른 ETF는 프록시가 없다(자체 이력만 사용).
- `category`: 네이버 분류 이름(국내 시장지수, 국내 업종/테마, 해외 주식, 원자재 등).

## 4. 출력

- `config/universe_kr_all.csv`: 기존 유니버스와 같은 열(`ticker,name,category,enabled,group,pension_ok,retirement_ok,risk_asset,proxy,note`). 이름은 네이버의 한글 이름.
- `config/universe_kr_all.meta.json`: 생성 시각, 데이터 기준일, 원본 개수, 제외 사유별 개수, 야후 누락 티커, 그룹 수, 기준값(상관 0.9, 창 252일, 최소 63일).
- 기존 `config/universe_kr_pension.csv`, `universe_kr_etfs.csv`와 기존 연구 결과·문서는 그대로 둔다.

## 5. 구성 요소

- `src/etf_momentum/universe_builder.py` (네트워크 없는 순수 함수, 테스트 대상)
  - `filter_etf_list(items) -> pd.DataFrame`: 제외 규칙 적용, 제외 사유 집계.
  - `correlation_groups(returns, threshold=0.9, min_overlap=63) -> pd.Series`: 티커별 그룹 번호(혼자이면 없음).
  - `build_universe(listing, prices, proxies) -> pd.DataFrame`: 계좌·자산 표시, 그룹 이름, 프록시 이전.
- `scripts/build_universe.py`: 네이버 목록 받기 → 필터 → `download_prices(raw=True)`로 야후 가격 받기(누락 티커 제거) → 그룹 → 파일 저장. 옵션: `--output`, `--end`(데이터 기준일 고정), `--cache-dir`, `--refresh`.
- 전략 파일: `config/strategies/pension.json`, `retirement.json`의 `universe`를 `config/universe_kr_all.csv`로 바꾸고 `version`을 2로 올린다. 나머지 규칙(상위 4개, 그룹당 1개, 거래대금 10억, KODEX 200 시장 필터, 프록시 사용)은 같다.

## 6. 사용 흐름

```bash
uv run python scripts/build_universe.py          # 매달 초: 새 상장 반영, 그룹 다시 계산
uv run etf-momentum rank --strategy config/strategies/pension.json
```

- 유니버스 파일 내용은 신호 기록의 `config_hash`에 들어가므로 어떤 목록으로 선정했는지 남는다. 유니버스 파일을 커밋하지 않고 `rank`를 실행하면 기록의 `code_dirty`가 참이 된다. README에 다시 만든 뒤 커밋하라고 적는다.

## 7. 비교용 검증 (한 번)

- 전체 유니버스로 연금저축 워크포워드를 기존과 같은 설정(robust grid, 10억, 10bp, 프록시 사용, `--end 2026-10-07`)으로 한 번 실행한다: `results/walkforward/kr_all_pension_10eok_10bp_robustgrid_tvoff`.
- `scripts/research_tables.py`에 "전체 ETF 유니버스(비교용)" 표를 추가하고, 연구 문서에 60개 결과와 나란히 적는다. 생존 편향 주의 문구를 함께 적는다.
- 그룹은 현재 시점 상관으로 정한 것이라 과거 백테스트에는 사후 정보가 들어간다(기존 60개 그룹도 같은 한계).

## 8. 오류 처리

- 네이버 목록을 받지 못하거나 형식이 다르면 멈춘다(기존 유니버스 파일을 덮어쓰지 않는다).
- 현금 ETF나 벤치마크가 목록이나 야후 가격에 없으면 멈춘다.
- 저장은 임시 파일에 쓴 뒤 바꿔치기해, 중간에 실패해도 기존 파일이 깨지지 않게 한다.

## 9. 테스트 (네트워크 없음, 합성 자료)

| 영역 | 확인할 것 |
|---|---|
| 제외 규칙 | 분류 3·6·7 제외, 다른 분류의 `레버리지`/`인버스`/`2x` 이름 제외, 커버드콜·합성 포함, 현금 ETF 강제 포함, 사유별 개수 |
| 그룹 | 0.9 이상 쌍 묶음, 사슬(A–B, B–C 높고 A–C 낮음)에서 A·C 분리, 63일 미만 겹침은 묶지 않음, 결과가 입력 순서와 무관 |
| 유니버스 | `retirement_ok`(합성·선물), `risk_asset`(현금만 0), 그룹 이름 = 거래대금 최대 ETF, 혼자인 그룹은 빈 값, 프록시 이전 |
| 야후 누락 | 가격이 없는 티커 제거·보고, 현금·벤치마크 누락 시 오류 |
| 호환 | 만든 CSV를 `load_universe`가 읽고 중복 티커가 없음, 전략 파일 v2 로드 |
