## 독립 보고서의 증거 대조

Gemini의 첫 독립 결과 JSON과 전체 374개 테스트 실행은 실제 로그로 확인됐고, GPT의 격리 재실행에서도 12개 `matches_expected` 묶음이 모두 일치했다. 다만 첫 서술 보고서는 원자료와 다른 파일 해시·존재하지 않는 API/심볼·설정 설명·확인되지 않은 집계를 포함해 그대로 수락하지 않았다. `report_accuracy_checklist.md`와 별도 Orca 후속 작업으로 보정했다.

보고서 보정은 제품 결함 수정과 구분한다. 원 독립 스크립트의 입력/계산 결과를 구현자의 예상값에 맞춰 바꾸지 않았으며, GPT의 API 인자 오타 지적은 재현 코드 호출 오류에 대한 것이다. 보고서의 구체적 후보 수·함수명·예외 설명과 검증 제한도 실제 파일에 맞추도록 별도 사실 대조를 진행한다. 초안은 임시 `verification_draft_rejected.md`로만 보존하며 최종 보고서를 우선한다.

따라서 모델의 완료 선언 자체가 최종 승인 증거는 아니다. 이 실행의 최종 판정 근거는 고정 소스 해시, 재현 입력과 출력, 실제 테스트 로그 및 문서와 코드의 직접 대조다.
