## 소스와 감독 기록

시작·최종 HEAD는 `e596368be6d76bd604361b3a1d84d8af9a978399`로 같다. 검증 대상은 이 커밋에 필요한 미커밋 수정을 더한 작업 트리다. Claude 완료 후 소스·테스트·설정·요구사항 등 68개 파일을 고정했고, 독립 검증 및 최종 점검에서 모두 일치했다.

- 소스 manifest SHA-256: `a9c2e85fda59d1d572421f93b37b738652c560b38fdb3f208c06800f8070c049`
- 추적 제품 diff SHA-256: `a37c657463af9a7cbd93f2f9b43c69477dd6ed3f3c25e2a824d61ece1f0111e8`
- manifest는 `sha256(json.dumps(files, sort_keys=True).encode())` 기준. Gemini 최초 before 집계는 compact 직렬화여서 달랐지만 개별 파일 불일치는 0건이고, after는 지정 직렬화로 일치했다.

실제 Orca Run `run_2d8c6f88a708`에서 GPT가 설계·조정·수락, Claude가 유일한 제품 코드 편집, Gemini가 독립 검증을 수행했다. Claude 모델은 세션의 system/client 표시상 Opus 5.5 high, Gemini는 실제 화면상 Gemini 4 Argon medium이었다. 런타임 provider를 확인했으나 서버 API 수준 모델 신원 확인은 아니다.

## 한계와 보존 범위

- 전체 788종 거래대금 캐시가 없어 729종이 로컬 거래대금 자료로 충족되지 않는다. 전체 유니버스 유동성 필터 포함 선정·백테스트는 미검증이다.
- 룩백·SMA·변동성의 행 기반 창은 변경하지 않았다. 여러 짧은 공백이나 워밍업 공백이 누적되면 전체 누락 행은 5개를 넘을 수 있다. 이번 수정이 과거 세션을 복원하지는 않는다.
- `compare`·`walkforward` 세션 전달은 정적 코드 대조와 기존 스위트로 확인했다. 새 전체 그리드 연구는 실행하지 않았다.
- 12개 고정 가격 캐시의 신선도 판정 변경 0건은 관측한 국소 결과다. 공식 성과 불변이나 외부 시세 정확성의 증명이 아니다. 외부 시세·휴장 공고 조회도 하지 않았다.
- **커밋·푸시·공식 연구 결과 재생성 없음.** 운영 데이터·기존 결과에 대한 쓰기를 수행하지 않았고 기존 workflow 안내 문서도 보존했다. 결과물은 미커밋 제품 수정·회귀 테스트·이 폴더의 리뷰 문서와 임시 재현 자료다.
