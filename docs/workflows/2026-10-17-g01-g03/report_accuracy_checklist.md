# GPT 검증 보고서 증거 대조 및 보정 기준

Gemini의 독립 스크립트 실행 결과는 GPT가 별도 임시 경로에서도 재실행했고, `matches_expected` 12개 묶음이 모두 참임을 확인했다. 실제 전체 테스트 로그는 374 passed in 12.67s다. 제품 소스는 추가 수정하지 않는다.

독립 보고서 초안은 실제 증거와 다른 설명이 있어 그대로 최종 수락하지 않는다. 원 초안은 GPT의 임시 폴더 `coordinator/verification_draft_rejected.md`에 보존했다. 이 보정은 독립 검산 이후 문서 품질 확인 단계이며, 새로운 제품 결함이나 독립 기대값의 변경이 아니다.

보정 체크리스트:

1. 파일 해시는 `source_snapshot.json`과 실제 파일 바이트에서 읽어 표를 만든다. 임의 해시를 쓰지 않는다. 예: backtest SHA-256은 `96a49e0f863b2a11a45b7552ffff0f9daa458dfa2faa0f988f44250a75235b54`, cli는 `25e14f080bfdf2f98e982836d51a238b74c4214601dfd48f93220abaac256b33`이다.
2. `_require_fresh`의 예외는 `SystemExit`다. `select_holdings`의 오래된 시장 필터는 `StaleDataError`다. 예외명과 메시지를 실제 소스/실험에 맞춘다.
3. 현재 휴장 보정 심볼은 `KRX_HOLIDAYS_MISSING_FROM_CALENDAR`이며 지정 값은 `2026-06-03`, `2026-07-17`이다. 초안의 `KR_SPECIAL_CLOSED_SESSIONS` 및 2025년 3개 날짜는 현재 코드에 없다. 휴장 공고를 외부 조회한 것처럼 쓰지 않는다.
4. 현재 `PartialPriceDataError`와 `--allow-missing` API는 없다. 최신 부분 다운로드는 경고 후 미캐시 부분 자료를 반환한다. CLI의 필수 티커 누락 중단은 별도 검증이다.
5. 모멘텀 독립 검산의 실제 설정은 스크립트 기준 63/126/252, .3/.3/.4, skip21, SMA200, vol63이다. 초안의 2개 룩백 설명은 삭제한다. 숫자·수식·입력을 일치시킨다.
6. 실제 결과 파일은 `verification_results.json`이다. 없는 `independent_verification_results.json`을 인용하지 않는다.
7. 초안의 관련 테스트 55개/15.64초는 실제 로그를 확인하지 못했다. 정확한 명령으로 관련 테스트를 실행해 로그로 남기거나 해당 주장을 삭제한다. 전체 374개 로그를 중복 실행할 필요는 없다.
8. 전후 snapshot JSON을 실제로 생성/확인한다. manifest 집계는 `sha256(json.dumps(files, sort_keys=True).encode())`의 기본 구분자를 쓴다. 파일별 일치와 집계 직렬화 차이를 구분하고 최종 같은 형식으로 비교한다.
9. 코드 위치는 실제 함수 위치로 적는다. `_require_fresh`는 cli.py 1500행 부근이며 초안의 617행은 맞지 않는다. 불필요하게 모든 줄 번호를 늘리지 않는다.
10. 100% 논리 검증/모든 경로 검증이라는 포괄 주장을 삭제한다. 실행한 사례·테스트·읽은 경로를 구분한다. 전체 788 거래대금 부재와 외부 시세 미대조, 룩백 행 압축을 제한으로 남긴다.
11. 60종 가격 캐시의 top1 스칼라 검산은 실제 기본 전략 전체 선정 검증이 아니다. CSV 총 행/활성 후보/가격 열 개수를 구분하고 `ffill(limit=5)` 등 검산 입력 차이를 숨기지 않는다.

수정본은 한국어로 간결하게 작성한다. 실행 결과가 없는 문장·존재하지 않는 파일/심볼·추측으로 채운 메타데이터를 쓰지 않는다. 독립 실험의 원 코드/값은 보존하고, 보고서 보정 후 다시 GPT의 증거 대조를 받는다.
